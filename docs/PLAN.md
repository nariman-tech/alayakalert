# План внедрения AlayakAlert

## Кто пользуется и зачем

AlayakAlert — инструмент для специалистов, а не приложение для граждан. Он сокращает объём ручного
просмотра: из тысяч постов, чатов и эфиров показывает те, где видны признаки схемы, и объясняет почему.

| Пользователь | Что получает |
| --- | --- |
| Агентство по финансовому мониторингу (АФМ), полиция | Очередь подозрительных кейсов, сеть связанных аккаунтов, справку с цитатами для проверки |
| Регулятор рекламы и интернет-контента | Скрытая реклама казино у блогеров, сети с одним промокодом |
| Банки (антифрод, например Kaspi) | Признаки схем у получателей переводов: номер карты из поста связывается с переводами |
| Модераторы платформ и крупных каналов | Предварительная сортировка жалоб и эфиров |

## Этапы

### Этап 0. Сейчас — работающий прототип (готово)

- Проверка постов, чатов, расшифровок эфиров и выгрузок Telegram/WhatsApp.
- Риск 0–100 с объяснением, живой повтор эфира, сеть связей, метрики, второе мнение ИИ.
- Только синтетические данные, честные метрики.

### Этап 1. Пилот с одной службой — 3 месяца

**Цель:** проверить на реальном потоке и получить честные цифры.

- 2–3 аналитика работают в AlayakAlert параллельно со своей обычной работой.
- Материал — то, что уже приходит: жалобы граждан, обращения банков, ручной мониторинг.
- Каждый кейс аналитик отмечает: «подтверждено» или «ложное срабатывание». Кнопки уже есть.
- Раз в месяц правила улучшаются, а качество проверяется на **новых** размеченных кейсах, которые не
  использовались для улучшений.
- Установка на сервере службы: правила работают без интернета, данные не уходят наружу.

**Метрики пилота:** доля подтверждённых среди помеченных (точность); доля пропущенных среди найденных
аналитиками вручную (полнота); время от публикации до попадания в очередь; часы ручного просмотра,
сэкономленные за неделю.

### Этап 2. Автоматический сбор материала — 3–6 месяцев

- **Telegram:** публичные каналы и группы через официальный интерфейс для программ.
- **YouTube:** чаты эфиров и комментарии через официальный доступ Google.
- **TikTok, Instagram:** через соглашения с платформами (у них закрытый доступ для исследователей
  и госорганов).
- **Банки:** сигнал о многих мелких переводах на одну карту с комментариями «ставка», «участие»; номер
  карты из подозрительного поста связывается с банковским сигналом.
- **Жалобы граждан:** форма или бот, которые передают текст и ссылку в очередь.
- **«Снежный ком»:** найденный аккаунт ведёт к связанным через общий телефон, промокод или «победителя».

Принцип воронки: сначала широкий и дешёвый сбор, затем сортировка AlayakAlert, затем человек.

### Этап 3. Фото, видео, голос — параллельно с этапом 2

Всё превращается в текст, а дальше работает та же проверка:

- **голос** ведущего эфира → распознавание речи (русский и казахский; модели вроде Whisper работают
  на своём сервере);
- **картинки** (условия розыгрыша, скриншоты «выплат», номер Kaspi на экране) → распознавание текста
  плюс поиск одинаковых картинок у разных аккаунтов;
- **видео** → звуковая дорожка в распознавание речи, кадр раз в 2–3 секунды — в распознавание текста.

### Этап 4. ИИ на собственных серверах

- Второе мнение ИИ сейчас работает через внешнюю модель. Для госоргана модель разворачивается на своих
  серверах, чтобы тексты не уходили за пределы службы.
- ИИ разбирает спорные кейсы со «средним» риском и новые формулировки. Если ИИ видит то, что пропустили
  правила, этот случай становится кандидатом в новое правило.
- Правила остаются основой: они объяснимы, и их легко проверить.

## Что нужно для внедрения

| Ресурс | Зачем |
| --- | --- |
| Сервер службы (обычный, без видеокарты для правил; с видеокартой для речи и ИИ) | Работа без отправки данных наружу |
| 2–3 аналитика на пилот | Разметка и обратная связь |
| Юрист | Формулировки справок, соответствие статьям: лотереи без оператора — ч. 6 ст. 445-1 КоАП РК, реклама азартных игр, финансовые пирамиды — ст. 217 УК РК |
| Соглашения с платформами и банками | Доступ к потоку данных |
| Разработчик | Подключение источников, обслуживание |

## Риски и как их снижать

| Риск | Что делаем |
| --- | --- |
| Ложные обвинения честных людей | Система только помечает признаки, решает человек; снижающие факторы; контроль доли ложных срабатываний на пилоте |
| Мошенники меняют слова | Проверка механики, а не слов; ИИ для новых формулировок; ежемесячное обновление правил по отметкам аналитиков |
| Утечка персональных данных | Работа на сервере службы, ИИ на своих серверах, доступ по ролям, журнал действий |
| Закрытый доступ платформ | Начать с Telegram, YouTube, жалоб и банковских сигналов; соглашения с TikTok и Instagram — параллельно |
| Переобучение на своих же примерах | Качество измеряется только на новых кейсах, не использованных для улучшений; версии правил фиксируются |

## Как поймём, что внедрение удалось

- Точность на реальном потоке — не ниже 80%: из 10 помеченных кейсов 8 подтверждает аналитик.
- Время обнаружения схемы — часы, а не дни после жалоб.
- Ручной просмотр сокращается в несколько раз при том же числе найденных схем.
- Есть найденные сети, связанные общим телефоном, картой или промокодом, которых не было видно по
  отдельным жалобам.
